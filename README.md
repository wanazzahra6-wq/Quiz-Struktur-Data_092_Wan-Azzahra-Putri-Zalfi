**Deskripsi Singkat Setiap Program**
**soal_1.cpp (Pengelolaan Data Mahasiswa)**
Program ini dibuat untuk mengelola data mahasiswa seperti NIM, nama, dan nilai. Datanya disimpan menggunakan Single Linked List, lalu nilainya dapat diurutkan dari yang terkecil ke terbesar pakai Insertion Sort melalui Dynamic Array. Dilengkapi juga dengan fitur pencarian data menggunakan Linear Search dan Binary Search.

**soal_2.cpp (Sistem Manajemen Perpustakaan)**
Program ini mensimulasikan alur pelayanan di perpustakaan kampus. Di dalamnya menggunakan struktur data Queue untuk antrean peminjaman buku (FIFO), Stack untuk riwayat pengembalian buku (LIFO), dan Binary Search Tree (BST) untuk mengelola serta mencari ID buku agar lebih terstruktur.

**soal_3.cpp (Penelusuran Rute dan Jalur Kampus)**
Program ini memodelkan peta rute antar titik di area kampus menggunakan representasi Adjacency Matrix. Program ini bisa melakukan penelusuran jalur menggunakan algoritma BFS (Breadth-First Search) dan DFS (Depth-First Search), serta mencari rute terpendek antar lokasi menggunakan algoritma Dijkstra.

**soal_4.cpp (Hash Table Data Mahasiswa)**
Program ini mengelola data NIM dan nama mahasiswa dalam jumlah banyak menggunakan Hash Table berukuran 20. Program ini menerapkan metode Double Hashing untuk mengatasi tabrakan data (collision) serta dilengkapi fitur lazy deletion untuk menghapus data dengan aman.
